# GamepadMouse 手柄鼠标

把游戏手柄变成手机鼠标：悬浮箭头光标、左/中/右键、滚轮、按住拖动窗口/小窗、模拟手指滑动，**无需 Root**。

## 功能特性

- 悬浮箭头光标（Windows 指针样式，大小可调 10~56dp）
- L2 左扳机智能左键：短按=单击；按下 0~200ms 内移动左摇杆=**按住拖动窗口/小窗**；按住超时=持续长按（阈值可调）
- R2 右扳机右键：短按=点击，长按=按住
- 中键单击、滚轮上下
- 左摇杆移动光标；右摇杆向摇杆方向模拟手指滑动（距离 3~5cm、0.5s 一次、死区均可调）
- 左摇杆按下=拖拽切换；BACK=系统返回
- **所有按键含十字键可自定义**（15 键、18 种动作）
- 实时显示 Shizuku / 无障碍权限状态；一键复制日志
- 启动时屏蔽手柄对系统的控制，避免与系统按键冲突

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 悬浮窗 | 显示箭头光标 |
| Shizuku（推荐） | 真实鼠标 / 触摸注入（无线调试或 Root 启动） |
| 无障碍服务 | Shizuku 不可用时的兜底注入 |

## 快速开始

1. 从 Release 下载 `GamepadMouse-v1.1.13.apk` 并安装
2. 打开 App，开启悬浮窗 + 无障碍（推荐：用无线调试启动 Shizuku）
3. 点击「启动鼠标模式」

> iQOO / vivo（OriginOS）：请在系统设置里关闭本应用的耗电限制，避免后台被杀。

## 按键映射（默认）

| 按键 | 动作 |
| --- | --- |
| 左摇杆 | 移动光标 |
| 右摇杆 | 模拟手指滑动 |
| L2 | 智能左键（单击 / 拖动 / 长按）|
| R2 | 右键（点击 / 长按）|
| A | 左键单击 |
| BACK | 系统返回 |
| 十字键 | 光标微调 |

## 版本

- v1.1.13：拖动判定改为「按下 L2 后 0~200ms 内移动左摇杆=按住窗口拖动」，拖动跟手限幅防跳变
- v1.1.12：L2 智能左键状态机、十字键自定义
- v1.1.11：右摇杆手势滑动（距离/频率/死区可调）、返回键
- v1.1.8：按键自定义、左右键短按点击/长按按住

## 构建

纯 Android 工程（Gradle），包名 `com.gamepadmouse.app`，minSdk 24 / targetSdk 34；签名 keystore 位于 `app/keystore/`。
